## Information Architecture
The website is structured so that users can quickly access the most important information.
It’s a simple page designed to showcase the main sections of a CV, such as “About Me,” professional trajectory, and various projects that the user has worked on.

When browsing the “Trajectory” section, hovering the cursor reveals a link to download the user’s basic CV. Each section is framed with yellow borders to make visual separation clear and improve readability.

The content of the page follows a specific layout to first capture the viewer’s attention with an introduction, followed by the user’s educational and professional background. After reading that information, visitors can explore the projects the user has worked on.


## Visual Design
The overall design of the website aims to convey modernity and professionalism, supported by a minimalist aesthetic that keeps the focus on essential information.

An electric color palette combining blue, yellow, and black is used to evoke a futuristic tone. The primary font, Poppins, was chosen for its legibility and modern style. Clearly defined rounded sections help create a sense of balance and harmony.

The goal was to build a cohesive, intuitive page that is easy to navigate while maintaining a unique visual identity.
As a small detail, subtle transitions appear on buttons when hovered over — adding a sense of smooth and modern interactivity.
